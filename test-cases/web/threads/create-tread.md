# Створення треда: Валідація лімітів та посилань

## Preconditions
1. Користувач авторизований на одному з середовищ:
   - https://stage.ua.example.com
   - https://stage.by.example.com
   - https://stage.example.com
2. Користувач має принаймні один власний блог.

## Steps
1. [ ] **Action: Відкриття модалки**
   1. Натиснути на кнопку "+" (Floating Action Button) або "Новий тред" у профілі.
   
   **Expected:**
   1. Відкривається модальне вікно "New thread".
   2. Елементи форми (`avatar`, `blog-selector`, `text-input`, `image-upload`, `tags`) доступні для взаємодії.

2. [ ] **Action: Перевірка лімітів тексту**
   1. Ввести в поле тексту 5001 символ.
   
   **Expected:**
   1. Система не дозволяє введення більше 5000 символів (атрибут `maxlength="5000"`) або відображає лічильник з помилкою валідації.

3. [ ] **Action: Перевірка лімітів медіа**
   1. Завантажити 4 зображення (.jpg/.png).
   2. Спробувати завантажити 5-те зображення.
   
   **Expected:**
   1. Кнопка додавання медіа стає неактивною (`disabled`) або з'являється попередження про ліміт (max 4).

4. [ ] **Action: Валідація внутрішнього посилання**
   1. Очистити текст та ввести: "Тест лінка https://ua.example.com/".
   2. Натиснути "Опублікувати".
   3. Перейти до створеного треда.
   
   **Expected:**
   1. Тред успішно створено.
   2. Посилання відображається як активний тег `<a>`.

5. [ ] **Action: Валідація зовнішнього посилання**
   1. Створити новий тред з текстом: "Зовнішній лінк https://google.com".
   2. Опублікувати та перевірити результат.
   
   **Expected:**
   1. Тред створено.
   2. Посилання https://google.com відображається як **звичайний текст (Plain text)**, без можливості кліку.

## Expected Results
Система суворо дотримується лімітів контенту (5000 симв, 4 фото) та забезпечує безпеку через фільтрацію зовнішніх посилань.
