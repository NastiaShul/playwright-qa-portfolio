# Керування тредом: Редагування, Видалення та Права доступу

## Preconditions
1. Користувач А (Автор) має опублікований тред.
2. Користувач Б (Інший юзер) авторизований.
3. Користувач В (Модератор) авторизований.

## Steps
1. [ ] **Action: Перевірка прав доступу до меню**
   1. Авторизуватися як Користувач Б.
   2. Перейти на сторінку треда Користувача А.
   
   **Expected:**
   1. Кнопка меню "..." (`data-test="thread-menu-trigger"`) **відсутня** для звичайного користувача.

2. [ ] **Action: Редагування треда автором**
   1. Авторизуватися як Користувач А.
   2. Натиснути "..." на своєму треді та обрати "Редагувати".
   3. Змінити текст та додати/видалити зображення. Натиснути "Зберегти".
   
   **Expected:**
   1. Відкривається модалка редагування (аналогічна модалці створення).
   2. Після збереження контент треда оновлюється без зміни URL.
   3. З'являється системний тост "Зміни збережено".

3. [ ] **Action: Видалення треда модератором**
   1. Авторизуватися як Користувач В (Модератор).
   2. Відкрити меню "..." на треді Користувача А.
   3. Натиснути "Видалити" та підтвердити дію.
   
   **Expected:**
   1. Модератор бачить кнопку видалення.
   2. Після видалення тред стає недоступним за прямою лінкою (404 або повідомлення "Тред видалено").

4. [ ] **Action: Перевірка видалення автором (UI Sync)**
   1. Авторизуватися як Користувач А.
   2. Видалити свій інший тред.
   3. Перейти в профіль (вкладка "Треди") та в "Мою стрічку".
   
   **Expected:**
   1. Тред миттєво зникає зі списків у профілі та стрічці без ручного оновлення сторінки.

## Expected Results
Кнопка керування доступна лише автору та модератору. Операції редагування та видалення працюють коректно з миттєвим оновленням інтерфейсу.
